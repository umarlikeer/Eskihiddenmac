# ElektrTarmoqGA — Android офлайн илова лойиҳаси

Илова интерфейси ўзбек кирилл ёзувида. У `DATA_Q14.txt` да берилган 13 та ишчи тугун, 20 та шохобча ва баланс тугуни маълумотлари билан ишлашга мўлжалланган.

## Илова режимлари
- **Бошланғич режим** — бошланғич тармоқ режими ва актив қувват исрофи.
- **Реактив қувват** — генетик алгоритм орқали Q ўзгарувчиларини оптималлаштириш.
- **Трансформатор** — комплекс трансформация коэффициентларини оптималлаштириш.
- **Биргаликда** — Q ва трансформатор коэффициентларини бирга оптималлаштириш.

## APK ҳақида муҳим гап
Ушбу архив — Android Studio лойиҳаси, **тайёр APK файли эмас**. Ҳозирги муҳитда Android SDK ва Gradle йўқлиги учун APK бинарини компиляция қилиб текшириш имкони бўлмади. Шунинг учун архивни APK деб кўрсатмаяпман.

## APK ни GitHub Actions орқали олиш
1. ZIP архивни очинг ва `ElektrTarmoqAndroid` папкаси ичидаги файлларни ўз GitHub репозиторийингизга юкланг.
2. GitHub репозиторийида **Actions** бўлимига киринг.
3. **Build Android APK** workflow'ини танлаб, **Run workflow** ни босинг.
4. Build муваффақиятли тугаса, run саҳифасининг **Artifacts** қисмида `ElektrTarmoqGA-debug-apk` архивини оласиз.
5. Архивни очинг; ичида `app-debug.apk` бўлади. Уни телефонга кўчириб ўрнатиш мумкин. Android хавфсизлик ойнаси чиқса, фақат ўзингиз ишонган манбадан олинган APK учун ўрнатишга рухсат беринг.

Биринчи cloud build Gradle, Android SDK, Chaquopy ва Python пакетларини интернетдан юклайди. Ўрнатилган илова ҳисоблаш пайтида интернет талаб қилмаслиги кўзда тутилган.

## Лойиҳани маҳаллий йиғиш
Android Studio'да шу папкани очинг, Gradle синхронлашувини бажаринг ва `Build > Build Bundle(s) / APK(s) > Build APK(s)` ни танланг. Керакли Android SDK platform 35 ҳамда Java 17 бўлиши керак.

## Ҳисоблаш моделининг ҳолати
- Python ҳисоблаш ядроси ва генетик алгоритм лойиҳага қўшилган.
- `tests/smoke_test.py` — Linux/desktop Python муҳитидаги оддий smoke-test; бу Android APK компиляциясини ҳам, муҳандислик моделининг тўғрилигини ҳам тасдиқламайди.
- Синов ҳисобида `DATA_Q14.txt` учун бошланғич актив исроф тахминан **8.998 МВт** чиқди. Бу рақам фақат шу лойиҳадаги Python моделининг натижаси; уни ҳақиқий тармоқ натижаси деб қабул қилманг.
- Трансформаторни оптималлаштиришнинг қисқа синовида исроф ҳар доим ҳам камаймади. Шу сабабли илмий ёки амалий муҳандислик қарорларида ишлатишдан олдин натижаларни асл `OPT_Q.PAS1111.PAS` дастури билан бир хил кириш маълумотларида солиштириб, мутахассис текширувидан ўтказиш зарур.

## Техник тузилма
- `app/src/main/java/uz/uzbek/powerga/MainActivity.kt` — Android интерфейси.
- `app/src/main/python/mobile_api.py` — интерфейс ва ҳисоблаш модели орасидаги API.
- `app/src/main/python/ga_core.py` — генетик алгоритм.
- `app/src/main/python/ga_optimizer.py`, `opt_q.py` — оптималлаштириш ва электр режимини ҳисоблаш.
- `app/src/main/assets/DATA_Q14.txt` — тармоқ маълумотлари.
- `.github/workflows/build-apk.yml` — GitHub Actions орқали APK йиғиш workflow'и.
